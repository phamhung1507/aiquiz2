Cấu Hình Gemini API Key

Khi bạn đưa trang web này lên GitHub Pages, mỗi người dùng có thể nhập Gemini API Key miễn phí của riêng họ (hoặc của bạn). Key chỉ lưu trực tiếp trên trình duyệt (`localStorage`) của máy đang dùng, đảm bảo an toàn bảo mật trên GitHub.

Cách lấy API Key miễn phí (30 giây):
  1. Truy cập Google AI Studio (aistudio.google.com)
  2. Đăng nhập tài khoản Google & nhấn "Create API Key"
  3. Sao chép mã bắt đầu bằng AIza... và dán vào ô trên.

Hướng Dẫn Đưa Lên GitHub Pages

Toàn bộ ứng dụng này đã được đóng gói gọn trong 1 file index.html duy nhất (bao gồm giao diện, bộ đọc file PDF/Word và kết nối Gemini AI). Bạn có thể đưa lên GitHub miễn phí chỉ với 3 bước:

Bước 1: Tải file mã nguồn về máy

Nhấn nút bên dưới để tải chính xác file index.html của trang web này về máy tính.

Bước 2: Tạo Repository trên GitHub
  • Đăng nhập GitHub.com và tạo một Repository mới (để chế độ Public).
  • Nhấn Add file → Upload files và kéo file index.html vừa tải vào, sau đó nhấn Commit changes.
Bước 3: Bật GitHub Pages
  • Trong Repository của bạn, vào mục Settings → Pages (menu bên trái).
  • Ở phần Branch, chọn nhánh main (hoặc master) rồi nhấn Save.
  • Đợi khoảng 1 phút, trang web của bạn sẽ hoạt động tại địa chỉ https://ten-ban.github.io/ten-repo/!
